# 🌐 WebTeche

**WebTeche** is a learning platform that helps users **learn HTML, CSS, and JavaScript** in a structured and interactive way.  
It provides **topic explanations, code examples, a live compiler, and game-based exercises** to make learning web development simple, practical, and fun.

---

## 📂 Project Structure

├── index.html # Homepage
├── html.html # HTML learning page
├── css.html # CSS learning page
├── javascript.html # JavaScript learning page
├── runcode.html # Interactive code compiler
├── randomconcept.html # Random concepts for quick learning(cheatsheet for user)
├── login.html # User login page
├── singup.html # User signup page

## 🚀 Features

- 📖 **Learn HTML, CSS, and JavaScript** with clear explanations.  
- ⚡ **Live Compiler** – run code in real-time.  
- 🎲 **Interactive Games & Random Concepts** – fun and engaging way to explore.  
- 🧠 **Code Examples & Brain Booster** – improve problem-solving skills.  
- 🔐 **Login & Signup Pages** – authentication UI.  
- 🎨 **Responsive & Clean UI** for a smooth learning experience.
